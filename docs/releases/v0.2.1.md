# Pi Companion 0.2.1

This update makes the optional desktop taskbar strip easier to place and reduces hover-name clutter. It preserves the approved sprite artwork, status bubbles, Office names, and automatic Pi observer connection.

## What's changed

- Smaller hover/focus agent names: 6px Press Start 2P with tighter spacing. Status bubbles and Office names retain their existing sizes.
- Flush desk placement: removes the native bottom margin, frontend spacing and transparent sprite-bottom gutter. The strip remains 104 logical pixels tall.
- Content-sized width: 452 logical pixels for three agents or 812 for six, clamped to the monitor's work area. Larger rosters remain scrollable with buttons, keyboard and trackpad.
- Choose Left, Center or Right under **Menu → Taskbar alignment**. Drag the strip's pixel grip for a free horizontal position; its vertical baseline stays anchored above the taskbar.
- Keyboard placement on the grip: Left/Right moves 1% of available travel, Shift moves 10%, and Home/End aligns to an edge.
- Placement is saved privately between launches. Monitor removal/reconnection, DPI/work-area changes and roster resizing retain bounded placement. Returning to Office restores its own monitor and rectangle rather than inheriting the strip's saved display.
- Drag cleanup covers release, cancellation, blur, mode changes, recovery, hiding and fullscreen transitions. Live-only agents, exact workspace filtering and tray/shortcut recovery remain intact.

## Download and upgrade

- `Pi-Companion-0.2.1-Windows-x64-setup.exe`: Windows x64 NSIS installer.
- `Pi-Companion-0.2.1-Observer.zip`: optional observer source and third-party notices. The installer already includes the observer.
- `SHA256SUMS.txt`: verify downloads with PowerShell's `Get-FileHash -Algorithm SHA256`.

The installer is **unsigned**. Windows may display an unknown-publisher or reputation warning. A formal release does not remove that warning. Microsoft WebView2 is required; if missing, installation downloads its bootstrapper/runtime and needs internet.

Existing Pi observer configuration continues to work. New users start Companion, open **Menu → Connect Pi**, and add the displayed observer path once to Pi's `extensions` setting. Normal Pi launches then connect automatically; no per-session command or environment variable is required. The app does not modify Pi settings. The bridge remains authenticated, read-only and local to `127.0.0.1:4318`; prompts, message contents and tool arguments/results are not sent.

## Verification and known limits

Local validation passed 313 tests: 155 frontend, 51 observer, eight pixel-authoring, and 99 Rust core/shell tests. TypeScript checks, production bundle verification, strict core/shell Clippy, formatting, source-boundary audit and independent source review also passed. All 15 sprite PNGs are unchanged. All 192 complete layered frames preserve every opaque pixel when the existing transparent bottom gutter is removed from placement.

Publication requires a fresh Windows build of this exact commit: full frontend/observer and Rust workspace tests, pixel tests, formatting, strict workspace Clippy and NSIS packaging. The workflow downloads and SHA-256 verifies all three release assets before publishing.

**Real Windows GUI acceptance remains outstanding.** The reviewed preview is an offline illustration. Automated tests do not prove physical mixed-DPI positioning, visible alignment with each taskbar configuration, WebView text/layout, pointer capture, native transparency, hit testing, z-order, auto-hide/fullscreen behavior, monitor reconnect, tray/hotkey recovery, accessibility or real-desktop installation behavior. The Windows workflow provides separate compile/test evidence, not a GUI pass. Please retain the recovery shortcut **Ctrl+Shift+P** and tray access when testing Taskbar mode.

See the taskbar release checklist for remaining native checks. Third-party notices are included; a project-wide source/artwork license has not been selected.
