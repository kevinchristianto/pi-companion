# Pi Companion 0.2.3

This update fixes the cramped empty Taskbar strip when idle agents are hidden and adds an idle-visibility toggle directly to the tray context menu.

## What's changed

- An all-idle Taskbar view uses three compact lines: **Idle hidden**, **N ready**, and **Use tray menu**. It no longer wraps the full Office message into a narrow desk slot or adds a nested paragraph scrollbar. Full accessible context and Office details remain available.
- Right-click the tray icon and use **Show idle / ready agents**. Its checkmark and the Office checkbox stay synchronized. The toggle does not restore or focus a hidden window, change window mode, or alter Pi sessions.
- The visibility choice is saved with the private display preferences. An existing renderer-only choice is migrated once without replacing a newer native/tray choice or losing saved strip placement.
- Only Ready (`idle`) agents are hidden. Active and attention states remain visible. The preference also filters the simulated demo without mixing it with live data.

## Download and upgrade

- `Pi-Companion-0.2.3-Windows-x64-setup.exe`: Windows x64 NSIS installer.
- `Pi-Companion-0.2.3-Observer.zip`: optional observer source and third-party notices. The installer already includes the observer.
- `SHA256SUMS.txt`: verify downloads with PowerShell's `Get-FileHash -Algorithm SHA256`.

The installer is **unsigned**. Windows may display an unknown-publisher or reputation warning. A formal release does not remove that warning. Microsoft WebView2 is required; installation downloads its bootstrapper/runtime if missing and can need internet.

Existing Pi observer configuration continues to work. No observer or protocol update is needed. The app remains read-only and local to `127.0.0.1:4318`; no Pi-control capability was added. The companion does not modify Pi settings.

## Verification and known limits

Local validation passed 368 tests: 206 frontend, 51 observer, 103 Rust core/shell and eight pixel-authoring tests. Typechecks, production build and asset/source checks, Rust formatting, core/shell Clippy and independent source review passed. All 15 sprite PNGs remain unchanged.

A separate unsigned GNU cross-build passed full Windows-target compilation, workspace Clippy and NSIS packaging. Its extracted app, x64 WebView2 loader and 23 resources were verified, and the test build was reported working. That test artifact is not the final release asset.

The formal release uses the established Windows MSVC workflow. Publication requires the exact release commit to pass frontend/observer checks, artwork checks, Rust workspace tests, strict workspace Clippy and NSIS packaging. Uploaded release assets are downloaded and SHA-256 verified before publication.

The working test-build report is not a complete native acceptance matrix. Mixed-DPI rendering, accessibility, taskbar auto-hide/fullscreen behavior, sleep/resume, hidden-window toggling and all recovery combinations have not been independently verified. Keep tray access and **Ctrl+Shift+P** available while checking Taskbar mode.

See [revision validation](../VALIDATION-STRIP-IDLE-TRAY.md) for coverage and limits. Third-party notices are included; a project-wide source/artwork license has not been selected.
